## 01 / whoami

I build Android apps, Kotlin Multiplatform tools, AI agents and the occasional privacy or security utility — usually offline-first, often at night.

- **Focus** — Android · Kotlin Multiplatform · on-device AI agents · security & privacy tooling
- **Now** — shipping [NOIR](https://github.com/Verlintas/NOIR) (Android privacy audit over adb) and [NovaBAIC](https://github.com/Verlintas/NovaBAIC) (local-first agent)
- **Principles** — no accounts, no telemetry, no GMS where avoidable; keep the data on the device
- **Org** — main developer at [NUSV](https://github.com/NUSV), open-source Android apps, tools and games
- **Languages** — 中文 / English
